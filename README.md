## ■ Featured Projects

### 🌐 Project 01 — Multi-Region AWS Web Application Deployment
Engineered an active-passive multi-region cloud deployment across US East (N. Virginia) and AP (Mumbai) to eliminate single points of failure, with latency-based health check failover simulating region outages and achieving **100% service availability**.

**Tech Stack:** `AWS EC2` `ECS Fargate` `ECR` `Route 53` `IAM` `Docker` `Git`

---

### 🔗 Project 02 — Scalable Web Service Deployment using Docker Swarm
Built a fault-tolerant containerized distributed cluster across EC2 instances, featuring a 3-node clustered quorum with dynamic Swarm ingress load balancing.

**Tech Stack:** `Docker Swarm` `AWS EC2` `Amazon Linux`

---

### 🛡️ Project 03 — DevSecOps CI/CD Pipeline for React on AWS
Authored a secure, declarative pipeline-as-code delivery workflow with automated Trivy filesystem and image CVE security gating before pushing to registry.

**Tech Stack:** `Jenkins` `Docker` `Trivy Scanner` `Amazon ECR` `AWS EC2`

---

### 🤖 Project 04 — NEXARA Chatbot App
Built an AI-powered conversational mobile app integrated with LLM response streams, supporting natural dialogue generated via the Gemini API across platforms.

**Tech Stack:** `Flutter` `Google Gemini AI API` `Dart`
